# Hewan Buas

Halaman web berbahasa Indonesia tentang 12 hewan buas: singa, harimau Sumatera, beruang kutub, buaya muara, hiu putih besar, komodo, macan tutul Jawa, serigala abu-abu, hyena tutul, orca, piton reticulatus, dan elang Jawa.

## Fitur
- Detail tiap hewan: habitat, status konservasi, makanan, cara berburu, dan fakta singkat
- Batang perbandingan kecepatan, berat, dan umur di alam liar
- Filter Darat/Perairan dan kotak pencarian
- Peringkat hewan berdasarkan kecepatan, berat, atau umur
- Tampilan terang dan gelap mengikuti pengaturan perangkat

## Cara menjalankan
Buka `index.html` di browser. Tidak perlu instalasi apa pun.

## Cara menayangkan lewat GitHub Pages
1. Unggah `index.html` dan `README.md` ke repositori GitHub.
2. Buka **Settings → Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**, lalu pilih branch `main` dan folder `/ (root)`.
4. Klik **Save**. Setelah satu atau dua menit, situs tayang di `https://USERNAME.github.io/NAMA-REPO/`.

## Catatan
Angka kecepatan, berat, dan umur adalah perkiraan umum, bukan data pasti. Font dimuat dari Google Fonts; tanpa internet halaman memakai font cadangan.
